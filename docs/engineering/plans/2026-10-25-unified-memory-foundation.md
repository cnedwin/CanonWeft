# 统一记忆底座实施计划

> 历史工程方案：保留技术决策、接口与验证设计；文中的迁移版本和计划状态仅适用于对应历史节点。当前实现状态见[实现状态](../../IMPLEMENTATION_STATUS.md)，当前版本见[版本基线](../../COMMUNITY_STACK_BASELINE.md)。

设计：docs/UNIFIED_MEMORY_ARCHITECTURE.md；总执行入口：docs/UNATTENDED_NOVEL_DELIVERY.md。

1. internal/memory 增加确定性类型与编译器：Scope（项目/分支/正史/权限/任务/视角/时间/存档）；Item（来源锚点、权威、有效区间、可见性、固定/相关性、依赖）；compile先过滤再闭包、必要缺失失败、预算不裁剪必要内容、输出选择/遗漏清单和哈希。
2. 同包增加有界TTL LRU缓存与抽象接口，键由完整Scope及源版本与编译参数生成；clone数据、容量限制、并发安全、缓存故障等于miss而非放宽权限。缓存不独占任何需要持久化的数据。
3. MySQL身份/修订/会话checkpoint/manifest的最小纵向，复用原件和项目权限；在同一批变更补齐备份/日志/保留分类再启用迁移，单次集中数据库验收。
4. /memory API与Vue记忆检查面板：可编辑候选、预览纳入原因/来源/预算、明确采用、查看版本；generation只消费固定且重新验证过的manifest。
5. 源增量提炼/摘要/叙事核心/高光覆盖；给每个必要Agent预置完整可编辑Skill、schema、示例/反例与模型用途绑定。模型输出不自动变canon。
6. 重要节点集中运行记忆隔离/时间/失效/缓存重建/恢复与中文长篇基准；完成后接小说向导和完整创作，而非停止在公共接口。

每步只跑与改变有关的有意义检查；依赖升级与数据迁移分开，避免复杂问题堆在最后。当前保留已验证通用Context路径，新的记忆编译完成后按调用点逐一接入，不一次替换全部现有生成与资格流程。
