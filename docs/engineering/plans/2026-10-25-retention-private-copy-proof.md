不重复保存原文，也不重新嵌入。以现有固定Unicode分块器生成范围、片段SHA和总数的证明，随来源引用历史保存；实际扫描严格校验私人索引所有片段及向量格式。

- [x] 来源正文/规范化策略/IP工作DTO/发布资料生成固定分块证明；来源年龄和版本不改变，旧证据缺失保持未确认。
- [x] 实际登记在同一事务核验index/part/source身份、完整分块摘要、范围、UTF8文本、数量、向量摘要与形状；多余/缺失片段拒绝，空白原文正确处理。
- [x] 历史固定来源仍用旧版本；允许相同原文字节SHA的当前可验证内容补充字面证明，不改绑定、采用状态或期限。无可验证证明则阻止清理。
- [x] 真实数据库验证篡改、缺片、回滚及历史来源；集中回归来源绑定和已发布索引。保持正式清理关闭，随后写入捕获及context/冻结输入。

## 实现与裁决

- TextCopyEvidence是引用版本的可选无正文证据，仅保存固定parser、全文SHA、rune数、片段数和有序范围/片段SHA的总摘要。记录不含向量或原文，旧记录仍可按原canonical字节读取。
- 私人索引使用原始业务版本与实际历史pin校验；原pin不存在时不能拿相同正文的新业务版本代替。业务证据存在但缺少分块证明时，计入UnboundSources并保持BLOCKED。相同全文SHA的已验证来源仅补充字面证明，不重写旧记录、不续期。
- 裁决：不另加副本证明表或新回执字段。原manifest/chunk来源摘要与不可变版本已经存在，登记使用锁定来源快照核对全部实际片段，未来执行库存需复用此校验；当前不把PARTIAL改为COMPLETE。
- 已发布与私人发布资料共用单次扫描的对象读取缓存，单对象32MiB、累计唯一对象64MiB；读取验证SHA与manifest大小。非UTF8作者二进制资料保留但不认证为文本。没有重新嵌入或模型调用。
