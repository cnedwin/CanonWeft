# 后台文件摄取与分单元恢复

> 历史工程方案：保留技术决策、接口与验证设计；文中的迁移版本和计划状态仅适用于对应历史节点。当前实现状态见[实现状态](../../IMPLEMENTATION_STATUS.md)，当前版本见[版本基线](../../COMMUNITY_STACK_BASELINE.md)。

真实模型调用默认关闭，底座与小说范围按路线图交付。本增量实现 F05 的实际文件摄取后台任务，并保持上传、私有编辑、候选采用分开。

## 固定契约

- 上传先保存不可变原文件和任务记录，返回任务标识。Temporal 执行；关闭页面不取消任务，不把解析正文放进工作流历史。
- PDF 按页、图片按图保存提取回执。已完成页不重复 OCR；每单元仍受现有进程隔离、资源和超时限制。TXT/Markdown/DOCX 的有界原生解析结果一次持久化，保留完整段落/对象覆盖账本。
- 输入文件哈希、解析器版本、OCR 方式固定。恢复时配置不匹配停止处理，不把不同解析器结果混在一份报告中。
- 暂停、继续、取消、当前权限/删除和进度修订号在每个处理边界复核。晚到单元不得绕过暂停/取消/撤权。未完成/失败单元保持明确原因，不假装完整。
- 全部单元完成处理后形成不可变 `source_imports` 报告；含待核对页的结果仍需作者明确接受遗漏。候选保存继续经过现有采用与发布门。
- 页面可查看任务、进度与覆盖报告，刷新恢复任务；导入后的手工编辑作为私有草稿持久保存，作者满意才生成候选。服务器草稿使用版本冲突保护，浏览器只记任务标识。

## 实施与验证

1. 扩展可信本地解析协调器的计划/单页入口。只由协调器启动受限子进程，禁止直接绕过作业限制。先写真实 PDF/图片单元测试。
2. 新增明确版本迁移的任务/私有编辑存储，更新固定备份、日志、归属/期限分类、旧版本转换和恢复禁用契约，再迁移持久测试库。
3. 服务提供上传/读取/列表/控制/单步推进。最终报告和任务完成同事务；重投返回原报告。新增 Temporal 工作流及 outbox 投递，不自行起普通循环代替持久调度。
4. Vue 文件入口接到后台任务，恢复、暂停/取消与私有编辑直通候选流程。同步导入 API 保留兼容，不能作为新入口的后台实现替身。
5. 真实 MySQL/Temporal 重启、分页回执、取消晚到、跨项目与角色撤销、备份恢复、浏览器刷新和手改保留全部验证。无付费模型调用。

该增量不减少 30 万字级小说、Recipe 执行、全量变更与保留清理的后续必需工作。
