## 作者界面与入口

工作室默认展示小说书架，支持本地搜索和继续开书草稿；IP项目、成员、模型与备份分别归入项目和工作室设置。开书保留八套完整预设和一页方案确认，已有草稿优先展示，示例、篇幅、初始角色及高级设置按需展开。

本书工作区按概览、故事规划、章节写作、人物与资料、审稿与导出组织；当前有效规划决定概览的下一步入口，任务助手按需打开。章节编辑器突出正文、保存、精修和专注，指定章节跳转、修订历史、旧稿取回与依据管理放入次级入口，面板输入和原有保存保护保留。普通章节编辑返回其原入口，资料变更、审稿、剧情账本、正文搜索和长稿导入保留各自的修改复核返回链。

界面整理不新增持久结构、权限、模型调用或执行资格；完整规划、写作、修改与发布流程仍以既有业务校验为准。

规划、角色资料、创作资料、审稿与导出采用相同的页首、返回操作、分区导航和主次操作层级。规划依据与表单分组按需展开；角色浏览、设定草稿、版本分支和知识任务分区保持各自输入；已有审稿记录与新审稿准备分开，待结算及结果未知仍明确显示；导出当前稿、历史稿本与对照分别组织，保留全部格式、版本和缺章确认。
