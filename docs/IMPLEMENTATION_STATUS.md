## 已有验证的性质

本地工程验证覆盖Go校验与服务、Vue交互、真实隔离MySQL/HTTP、持久任务与部分服务重启恢复、备份/隔离恢复、CPU嵌入和资料处理。模型响应替身只证明协议、编排、费用及数据保护，不证明真实模型结果。

MySQL9.7.4与Temporal1.32.1/mysql8已在全新独立实例上通过现有业务任务测试，覆盖等待、伪造批准信号拒绝、SDK worker停止与替代、明确采用后继续及发布完成。此次只重用该定向测试，临时库、账号和进程已清理；它补充版本组合的运行证据，不代表数据库/整个服务重启、存量迁移或生产切换。详情见[社区免费基线](COMMUNITY_STACK_BASELINE.md)。

作者入口与工作台的定向回归覆盖：预设完整性、免费预览无模型副作用、草稿与手改保护、保存竞态、阶段入口、选区边界、取消/过期候选、材料卡来源与独立记账上下文。相关测试位于 `backend/internal/novel`、`backend/internal/service`、`backend/tests/integration` 和 `web/tests`。

可靠性增补验证覆盖实际故障：批次详情和控制回执按版本及重叠请求水位更新，迟到结果不会撤回暂停或覆盖已显示的费用快照，后续正常对账仍可调整费用；生成任务列表的旧响应及旧权限错误不能覆盖操作后的新快照，当前权限拒绝仍会清除受保护内容；未采用的控制型记忆候选保持未确认通道，含该错误分类的旧上下文需重新编译且历史备份保留原校验语义。

生成面板的状态与选项读取限时15秒，较慢的手动预览限时60秒，包含响应体读取；超时后可继续轮询，离开面板会取消其未完成读取。已收到的权限拒绝不会因错误响应体或读取超时而变成普通网络错误，过期请求仍不能清除新快照。这些限制仅用于明确接入的GET，不自动重试写请求、取消生成任务或释放预算。模型选项支持原地重试和手动刷新：临时读取失败保留已有选项和手改输入，401/403清除旧选项；重试不发起生成。14项读取、恢复及权限浏览器用例通过，类型、格式和独立前端构建通过；此前原4项列表回归证据保留。

本地检索服务的启动/停止及首次密钥创建使用独占生命周期锁。确认进程树退出且18766端口无监听后，停止流程只清理原样未变的PID记录；身份不符、停止失败、监听残留或并发控制均拒绝，已被替换的记录保留。8项隔离文件/进程边界用例通过，没有以正式工作室或真实模型作为夹具；该结果不代表本轮重启或替换了正在运行的平台。

模型设置、预算和账单列表/历史的GET读取限时15秒，离开设置页会取消所属读取。读取超时释放只读加载状态，模型配置与预算有明确刷新入口；临时失败保留未保存配置和预算草稿，权限拒绝清除对应服务端快照。预算和对账写请求不受该GET时限影响，也不会因超时推断结果、重发或释放未知费用。3项独立回环HTTP浏览器流程已验证首屏恢复、卸载取消及未知写请求边界；它们不连接真实账户或模型，不能替代供应商账单核对。

Windows PowerShell 5.1 首次引导的长路径解压与完整性检查由受控便携 PowerShell 7 接续。独立目录的四工具安装、新 Python venv，以及冻结的1973文件源码快照的顶层完整依赖安装与前后端构建已通过。该次安装复用已校验的归档、模型和包缓存，仅补齐383字节官方Go模块元数据；安装入口退出0，产物哈希与源码未变均已核对。前端安装调用项目统一构建命令，保留类型检查并使用原生Vite配置加载。此结果不包含应用启动、数据库初始化、账号创建、数据恢复或之后的源码变更。

服务退出上下文已同时订阅 Interrupt 与 SIGTERM。独立Linux测试虚拟机及Windows定向检查覆盖信号、在途HTTP请求排空与测试消费者的清理钩子；生产隔离镜像和执行限制保持不变。该结果不代表完整Studio进程、数据库/任务服务退出、systemd、凭据保护或Linux部署已验收。

开写配置清单（N01/N11）复用仅工作室所有者可读的模型设置接口，集中显示服务端联网禁用策略、预算开关与可用额、常用五个及其他七个专业用途的配置缺口。版本保持固定；仅改名且Key未变时不要求重绑，停用、换Key、图片能力收回、价格过期或无法核验及币种不一致分别提示。诊断附加读取失败时不阻断已有设置；权限拒绝清除页面快照，定位操作不提交或覆盖草稿。价格与预算更改后需手动刷新清单。工程验证覆盖纯检查矩阵、真实隔离MySQL/HTTP和Vue回环HTTP流程，不含真实供应商、密钥解密可用性、文学质量或执行资格验收；源码更新不代表已更新运行实例。

批量连写工作台复用已有有界GET读取机制，章节、模型、批次记录、详情及候选对照读取限时15秒，离开页面取消所属读取。首屏失败可原地重试，临时失败保留作者要求、数量、预算输入和已知进度；当前权限拒绝清除受保护快照，旧批次迟到的权限错误不污染新视图。新增按章节标题/编号/状态查找、状态筛选、打开最近未完成批次和故障处理指引；打开记录不开始或恢复任务。写请求等待明确回执，不受GET截止或卸载取消影响，不自动重发或释放未知费用。浏览器工程检查不连接作品数据库或真实模型，不代替实际连续章节质量验收。

全书稿件管理（N03/N04/N07/N09/N11）在小说首页展示分卷目录、已保存正文字符数、私人稿/已采用稿状态及待核对依据，支持搜索、筛选、打开已有稿与下一待写章；未保存编辑不计入统计，没有私人稿时明确标注使用已采用稿。已有稿即使细纲待核对仍可打开，尚无稿件且细纲未确认时保留规划门。导出区支持选择两个已保存成书稿本，按稳定章节ID比较新增、移出、版本、相对次序、分卷和字符变化。版本哈希也包含写作依据，字符数相同不代表正文相同。复用已有只读预览接口，读取限时15秒，临时失败可重试，权限拒绝清理快照，切换版本或离开页面使旧结果失效。3项回环HTTP浏览器流程、受影响的原作者入口用例及类型/代码检查和独立构建通过；没有新增持久结构或模型调用，不替代长篇文学质量验证。

长篇改稿核对（N03/N06/N07）复用来源复核、章稿与影响清单。待复核页按资料类型、标题、编号和原因筛选，分页检查后可直达对应规划或章稿，保存后返回重新检查的清单并保留筛选条件。章节更新依据前先保存原稿，再只读对照其引用的旧细纲、设置和人物/世界版本与当前已确认依据；历史版本按确切修订和摘要核验，证据缺失时明确列出限制。只有明确确认才沿原流程更新引用并保存，正文、标题、引文、故事位置等内容保持原样；对照绑定保存稿与目标版本，上游再次变化须重新核对。手改、切换上下文或权限拒绝使旧对照失效；读取限时不取消或重发写请求。更新引用不等于重写、记账、审稿或正式采用，后续修改继续使用原地精修与既有发布流程，不自动调用模型。

该改稿流程已有4项Vue/回环HTTP流程、8项受影响的原写作台用例和2项隔离MySQL定向集成通过，覆盖私人稿隔离、确切历史版本（含超过版本列表窗口的旧设置）、无预览写入、过期确认拒绝和正文保留；类型/代码检查、定向Go vet及独立构建通过。测试使用的向量替身只位于测试文件，不能替代真实嵌入召回或文学质量验收。
