# 工具隔离试运行

文档核对：2026-10-28。本文定义专项契约与验证边界；当前工程实现、安装和资格状态见 [实施状态](IMPLEMENTATION_STATUS.md)。

工具版本在“Skill 研究与编辑 → 专业角色与工作流”中保存后，可以填写输入并发起隔离试运行。使用完整固定版本方法包，而非只截取 SKILL.md 或入口脚本。Python 可引用同包辅助模块；需要额外安装依赖、联网、超过当前资源边界的工具会被拒绝，不会转用宿主运行。

## 当前执行边界

- 入口来自方法包，包路径及全部内容固定。输入必须符合该工具版本的对象 JSON Schema，最多 256 KiB。
- 当前批准的 Linux 环境固定 256 MiB，执行超时最多 30 秒；输出最多 256 KiB。超出工具请求的范围不静默替换。无网络、宿主文件或数据库访问；全包只读，临时写入仅限客体工作目录。
- 提交事务同时记录任务、操作幂等回执和 outbox；Temporal 执行只传任务 ID。模型 Key 不进入输入或历史。
- 每次运行冻结能力清单、包、输入、运行镜像哈希。执行前、执行中和结果落库前检查权限、来源及能力撤销状态。
- 取消或撤权终止运行，晚到结果不采用。原任务状态及凭证保留。重复读取已撤销来源的旧结果时不返回内容。
- 必须同时满足正常退出和输出契约，才记录“试运行通过”。这一状态不授予生产资格，不自动激活工具，也不更改小说或正史。
- 执行最多重试三次；最终状态落库在数据库恢复前持久等待，不为落库失败重复执行工具。运行中重试仍受租约及最终事务检查。

## 接口与运行

`STUDIO_ISOLATION_ROOT` 由本地运行脚本设为已校验运行时目录。未配置时界面不开放提交；运行时缺失、损坏或版本不匹配时任务明确阻止。界面“已配置”不等于环境资格证明，实际执行再次校验运行时全部文件。

`POST /api/projects/:id/tool-trials` 接受 `operation_id`、`version_id`、`input_text`；相同幂等键且不同请求返回冲突。`GET` 列表分页、`GET /:job` 读取可见结果、`POST /:job/cancel` 取消。只有有编辑权限的成员可以提交；任务输入和输出只供发起人或项目所有者读取。跨项目 ID 不产生访问权限。

工具试运行输出为候选证据，不提供自动发布接口。长期资格评测、生产激活、批准依赖的锁定安装及完整 Recipe 执行由能力和调度模块承接，实际状态见 [实施状态](IMPLEMENTATION_STATUS.md)。试运行拒绝额外依赖是该执行环境的边界，不删除最终方案中的支持要求。
